# Hemova

Hemova is a blood-donation platform that helps communities connect with verified donation opportunities. It provides tailored experiences for donors, hospitals, blood banks, partner organizations, requesters, and administrators.

## Features

- Public landing, authentication, and onboarding flows
- Donor dashboard for appointments, donations, requests, matches, rewards, certificates, and profile settings
- Role-based dashboards for hospitals, blood banks, organizations, partners, requesters, and administrators
- Blood request and matching experiences
- FHIR-inspired types and data mappers for healthcare interoperability
- Responsive interface with light and dark themes

## Getting started

### Prerequisites

- Node.js 20 or later
- npm

### Install and run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server. |
| `npm run build` | Create a production build. |
| `npm run start` | Run the production server after building. |
| `npm run lint` | Run the configured lint command. |
